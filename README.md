# Nilotes Initiative Website

A responsive portfolio website for the Nilotes Initiative, built with plain HTML, CSS and JavaScript.

## Run it

1. Open this folder in VS Code.
2. Open `index.html` in a browser.

No Python server is required for this first version.

If you prefer a local server, from this folder run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Project structure

- `index.html` — website content and structure
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `assets/logo.jpeg` — supplied Nilotes Initiative logo

## Source

The portfolio content is based on the supplied Nilotes Initiative portfolio document.
